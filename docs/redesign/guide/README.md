화면은 **아이패드 에어 가로(1180×820) 그대로** 찍고, 설명은 화면 **아래 띠**에 적는다 —
자막이 화면 위를 덮으면 정작 설명하는 자리가 안 보인다. 앱을 iframe 으로 얹고 바깥 캔버스를
녹화하는 방식이고, 스크롤·클릭은 Playwright 가 iframe 안으로 실제 입력(휠·클릭)을 보낸다.

## 왜 URL 로 상태를 만드는가

이 화면의 상태는 **실제로 돌려서는 만들기 어렵다.** Day 3 까지 끝낸 화면을 보려면 강의를 아홉 개
들어야 하고, 복귀 연출(체크 튕김·막대·자물쇠 풀림)은 수업을 끝내고 돌아오는 **그 한 번**에만 나온다.
그래서 `/lessons` 에 시연용 파라미터를 뒀다. **DB 는 건드리지 않고 화면 안에서만** 끝낸 척한다.

| 파라미터 | 뜻 |
|---|---|
| `demoDay=3` | Day 1~2 를 다 끝낸 상태에서 **Day 3 이 오늘** |
| `demoLec=2` | 오늘 Day 의 **앞 2강**을 끝낸 상태 |
| `demoReview=1` | 오늘 Day 의 **복습까지** 끝낸 상태(하루 닫힘) |
| `demoFresh=2` | **방금 2강을 끝내고 돌아온** 연출 |
| `demoFreshReview=1` | **방금 복습을 끝내고 돌아온** 연출(완료 카드로 모핑) |
| `demoReviewToday=1` | 그 복습을 **오늘** 끝낸 것으로(완료 카드 붙잡기) |

demo 파라미터가 하나라도 있으면 **그 계정의 실제 진도는 섞지 않는다** — 설명용 화면에 예전 기록이
완료로 뜨면 무엇이 시나리오이고 무엇이 그 계정의 기록인지 구분이 안 된다.

## 장면 (영상 순서 = 아래 순서)

| # | 상태 | URL |
|---|---|---|
| 0 | 화면 한 바퀴 — 아래까지 훑고 올라온다 | `/lessons?demoDay=3` |
| 1 | 하루의 시작 0/4 — 강의 3(각 약 20분) + 복습(자물쇠) | `/lessons?demoDay=3` |
| 2 | 강의 1개 끝내고 복귀 — 체크 튕김·파문 1회·막대 1/4·다음 칸 깨어남 | `…&demoLec=1&demoFresh=1` |
| 3 | 3개를 내리 끝내고 복귀 — 0.14초씩 늦춰 차례로, 막대는 0/4 에서 출발 | `…&demoLec=3&demoFresh=3` |
| 4 | 강의 완료 → **복습 잠금 해제**(자물쇠가 별로 바뀌며 열림) | `…&demoLec=3&demoFresh=1` |
| 5 | 복습까지 완료 → 축하 뒤 **완료 카드로 모핑**(0.42s) | `…&demoReview=1&demoFreshReview=1` |
| 6 | 완료한 날 재방문 — 완료 카드 유지 + 자율학습 유도 | `…&demoReview=1&demoReviewToday=1` |
| 7 | 다음 날 — Day 4 가 오늘로, 지난 날은 초록 줄로 접힘 | `/lessons?demoDay=4` |
| 8 | Day 를 눌러 펼치고 접기 (240ms) | `/lessons?demoDay=4` |
| 9 | 지난 학습 펼치기 — 초록 줄 → Day 별 → 그날 강의 | `/lessons?demoDay=4` |
| 10 | 전체 보기에서 Day 를 고르면 그 Day 로 데려간다 | `/lessons?demoDay=4` → `전체` |

## 구현에서 알아 둘 것

- **하루는 복습으로 닫힌다.** 강의 3개만으로는 다음 Day 로 넘어가지 않는다(`dayDone`).
- **완료한 Day 는 그날 안에는 오늘 자리에 남는다.** 판단 기준은 "그 Day 의 복습을 **오늘** 끝냈는가".
  되돌리는 스위치는 `src/app/lessons/page.tsx` 의 `HOLD_COMPLETED_DAY` 한 줄 — `false` 면 예전처럼
  복습을 끝내는 즉시 다음 Day 가 올라온다.
- 복습 완료 기록은 아직 **테이블이 없어** localStorage 에 있다(`src/lib/todayPlan.ts`, Day → 끝낸 날짜).
  MVP1 에서는 `learner_progress` 옆에 복습 완료를 함께 두는 쪽이 맞다.
- '방금 끝냄' 표식도 localStorage 에 쌓인다(코드 목록 + 시각, 5분 TTL, 한 번 읽으면 지워짐).
  이어하기로 여러 강의를 끝내고 와도 **전부** 차례로 축하한다.
- `prefers-reduced-motion: reduce` 면 모든 연출이 멈추고 상태 표시만 남는다.

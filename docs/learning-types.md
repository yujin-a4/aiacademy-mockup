# 토익 학습 유형 32가지

진단 퀴즈 3문항 + 목표 설정의 하루 학습 시간으로 결정되는 4자리 코드.

## 코드 구조

| 자리 | 의미 | 선택지 |
|------|------|--------|
| 1번째 | 학습 방식 | F (빠르게) / T (꼼꼼) |
| 2번째 | 관리 방식 | D (강하게) / I (스스로) |
| 3번째 | 동기 유형 | P (점수) / A (성취감) |
| 4번째 | 하루 학습 시간 | L (15분) / M (30분) / N (1시간) / X (1시간 이상) |

---

# 화면 캡처 — 수업 완료 화면 · 실전 문제 화면

2026-08-04 캡처. 재현은 **`/dev/screens`** (개발 서버) — 여기 있는 상태를 전부 URL 하나로 띄운다.
화면을 고치면 이 폴더의 그림은 낡는다. 다시 찍을 때도 `/dev/screens` 에서 찍으면 된다.

## 수업 완료 화면

순서: **① 수업 완료 → ② 실전 정답률 → ③ 성취 문구(있는 것만) → ④ 다음 행동**
②③은 몇 초 뒤 자동으로 넘어가고, 탭하면 바로 건너뛴다.

| 파일 | 화면 | 언제 나오나 |
|---|---|---|
| `end-01-opening` | 수업 완료 + 풀이시간 | 항상 |
| `end-02-accuracy-perfect` | 실전 정답률 — 만점 | 실전 문항이 있으면 항상 |
| `end-03-accuracy-partial` | 실전 정답률 — 일부 오답 | 〃 |
| `end-04-feedback-perfect` | 🏆 완벽 풀이 | 실전 만점 |
| `end-05-feedback-high-score` | 🎯 실전 고득점 | 실전 80% 이상 (만점 제외) |
| `end-06-feedback-streak` | 🔥 3연속 정답 | 최대 연속 정답 3 이상 |
| `end-07-feedback-recap-perfect` | 🧠 표현 완벽 정리 | 세션 정리 만점 |
| `end-08-feedback-first` | 🌟 첫 완주 | 이 파트 첫 완료 |
| `end-09-action-today-remaining` | 다음 행동 — 오늘 분량 남음 | 하루 목표(3강) 미달 + 다음 강의 있음 |
| `end-10-action-today-done` | 다음 행동 — 오늘 분량 완료 | 하루 목표 달성 |

**성취 문구는 0장일 수 있다.** 위 조건을 하나도 못 채우면 ③ 자체를 건너뛴다 —
잘한 게 없으면 말하지 않는다는 규칙. (이 빈 상태는 `/dev/screens?s=end-fb-none` 에 설명만 있다)

**'배지'가 아니다.** MVP에서는 그 자리에서 보여주고 끝나는 피드백이고, 모이거나 프로필에 쌓이지
않는다. 화면에 '배지'라는 말을 쓰지 않는다. (규칙은 `src/lib/sessionBadges.ts` 맨 위 주석)

## 실전 문제 화면

| 파일 | 화면 | 볼 것 |
|---|---|---|
| `practice-p1-photo` | Part 1 사진 묘사 | 보기가 **A/B/C/D 만** — 내용은 음성. 상단 [음원 듣기] |
| `practice-p2-audio-options` | Part 2 질의응답 | 질문·보기 **둘 다** 음성으로 가려짐 |
| `practice-p3-conversation` | Part 3 짧은 대화 | 보기는 인쇄됨(실제 시험지대로). 스크립트는 채점 전 잠금 |
| `practice-p4-talk` | Part 4 짧은 담화 | 〃 |
| `practice-p5-blank` | Part 5 단문 빈칸 | 문장 카드 + 보기 |
| `practice-p5-graded` | Part 5 채점 후 | 정답 초록 / 내 답 빨강 + 보기별 해설 |
| `practice-p6-split` | Part 6 장문 빈칸 | **지문(좌) \| 문항(우) 2분할**, 가운데 리사이즈 핸들. 지금 푸는 빈칸이 지문에서 파랗게 |
| `practice-p7-split` | Part 7 1지문 독해 | 2분할 + 하단 문항 페이저 |
| `practice-p7-double-passage` | Part 7 이중지문 | 좌측 칸에 지문 탭 |
| `practice-p7-drawing-on` | Part 7 필기 켬 | 필기 도구 바(연필·형광펜·지우개) |

공통으로 하단에 **문항 페이저**(`← 이전 [1][2][3] 다음 →`)가 있다. 번호 칩 색으로 진행이 보인다 —
회색=안 품, 파랑=고름, 채점 후 초록/빨강. `채점하기`는 전 문항을 다 골라야 열린다.

## 남은 것

- **완료 화면은 폰 프레임으로 찍혀 있다.** 실전 화면을 iPad Air 가로로 맞추기 전에 찍은 것이라
  기기 기준이 서로 다르다. 태블릿 기준으로 통일하려면 `/dev/screens?s=end-*` 를 다시 캡처하면 된다.
- Part 6·7 2분할에서 **필기 획은 지문 스크롤을 따라가지 않는다** — 캔버스가 바깥 영역에 고정돼 있다.
  수업 화면도 같은 구조라 원래 있던 한계.

# 강사 상세 페이지 구성 — 개발사 전달용

> 온보딩 강사 선택 → **"OOO 강사 자세히 보기"**로 진입하는 화면의 구성 정의입니다.
> 작성일 2026-08-03 · 대상 MVP1

---

## 1. 상단 — 강사 프로필

### 1-1. 강사 사진
정지 이미지 한 장입니다.

### 1-2. 강사 이름
이름 옆에 전문 분야 배지가 붙습니다. (예: "목표 자극 전문")

### 1-3. 해시태그
그 강사의 강의 특징을 나타내는 태그입니다. 강사당 5개 내외입니다.

- 예: `#스파르타` `#오답소거` `#압축전략` `#목표자극` `#고득점`
- **YBM이 확정해서 전달합니다.** 개발사가 생성하지 않는 고정값입니다.

### 1-4. 매칭률
"OOO님의 성향과 **80%** 매칭" 형태로 노출됩니다.

- 온보딩 성향 응답과 강사의 성향 코드를 비교하는 **로직 기반 산출값**입니다.
- 산식은 [4-2](#4-2-매칭-산식) 참고.

### 1-5. 매칭 사유 한 줄
매칭률 바로 밑에, 왜 이 강사가 맞는지를 설명하는 문장입니다.

- 예: "도전적인 문제를 즐기고 목표 자극으로 동기를 찾는 성향에 딱 맞아요."
- 성향 조합에 따라 문장이 달라집니다. **경우의 수가 정해져 있어 YBM이 전부 작성해 전달합니다.**

### 1-6. 강사 한마디
강사의 코칭 스타일이 드러나는 한 문장입니다.

- 예: "군더더기 없이 핵심만 빠르게요."
- 강사당 1개, 고정값입니다.

### 1-7. CTA 버튼
**`이 강사 선택하기` 하나입니다.** 누르면 바로 대시보드로 이동합니다.

## 2. 하단 — 탭 2개

### 2-1. 강의 소개 탭

이 강사가 어떻게 가르치는지에 대한 소개 글입니다.
**"소제목 + 본문" 형태의 블록이 반복되는 구조**로 만들어 주세요.

- 블록 개수는 강사당 2~3개입니다.
- **소제목은 고정값이 아니라 콘텐츠에 따라 달라집니다.** 특정 소제목을 화면에 박지 말아주세요.
- 본문에는 평문과 불릿 목록이 모두 들어갈 수 있습니다.
- 실제 소제목과 본문은 **YBM이 강사별로 작성해 전달**하며, 그대로 노출해주시면 됩니다.

**데이터 처리:**
admin 등록 기능은 이번 단계 범위에서 **제외**합니다. 고정값으로 넣되, 화면 코드에 직접 박지 말고
**강사별 데이터로 분리**해 주세요. 이후 admin에서 관리하도록 전환하는 것을 전제로 합니다.

### 2-2. 커리큘럼 탭

**대제목:** `OOO님을 위한 맞춤 커리큘럼`

**구성 (위에서부터 순서대로):**

| 요소 | 내용 | 데이터 출처 |
|---|---|---|
| ① 대제목 밑 한 줄 | 이 배치를 제안하는 근거 | 온보딩 응답 조합 (YBM 제공 문안) |
| ② 강좌 요약 | 목표 점수 / 수업 횟수 / 수강 기간 | 온보딩 응답 + 배치표 |
| ③ 전체 강의 목록 | 주차 → 일자 → 그날의 강의 | **강의 DB + 강사별 배치표** |

#### ② 강좌 요약 — 3개 항목

| 항목 | 값 | 출처 |
|---|---|---|
| 목표 점수 | `750 목표` | 온보딩에서 응답한 목표 점수 |
| 수업 횟수 | `주 5일 (총 20일)` | 배치표의 일자 수 |
| 수강 기간 | `4주 완성` | 배치표의 주차 수 |

#### ③ 전체 강의 목록 — 주차 → 일자 → 강의

**평면 목록이 아닙니다.** 아래 3단 구조로 보여주세요.

```
1주차  LC Part 2·1 우선 + RC Part 5 기본 병행        ← 아코디언 헤더 (주차 제목)
  D1   LC 3강 · LC 4강                               ← 그날 배치된 강의
       복습 · 동일 유형 오답 문제 풀이                 ← 복습 항목
       학습 자료 · Part 2 오답 소거 포커스 노트        ← 있는 날만
  D2   LC 5강 · LC 6강
  …
  주차 목표 · LC Part 2·1로 듣기 점수 기반을 만들고…   ← 주차 하단
```

- 4주 × 5일 = **D1~D20**, 하루에 강의 **2~4개**가 배치됩니다.
- **어떤 강의가 며칠차에 들어가는지가 강사마다 다릅니다.** 이 구조가 없으면 강사별 차이가
  화면에 드러나지 않아 "맞춤 커리큘럼"이 성립하지 않습니다.
- 각 일자에는 **복습 항목**이 붙고, 일부 날짜에는 **학습 자료**가 추가로 붙습니다.
- 주차마다 **주차 제목**과 **주차 목표**가 있습니다. (목표가 비어 있는 배치도 있습니다)
- 4주차는 정규 강의가 아닌 **시험 직전 특강**이라 DB 강의와 연결되지 않습니다. 문구만 노출합니다.

**데이터 처리 방식:**

- 강의명·파트·순서는 **강의 DB를 그대로 뿌려주시면 됩니다.**
- 어느 강의를 며칠차에 배치할지만 강사마다 다르고, 이건 **YBM이 강사별 배치표로 별도 전달**합니다.
- 배치표에는 **강 번호만** 들어갑니다. 제목·파트는 DB에서 조인해 주세요.
  → 배치표에 제목을 같이 적어두면 DB에서 강의명이 바뀔 때 두 곳이 어긋납니다.

> **참고:** 현재 목업에는 강의별로 `수업 가능 / 준비 중` 뱃지가 붙어 있습니다.
> 이건 문항이 아직 안 들어간 강의를 구분하기 위한 **목업 전용 표시**이며,
> MVP1 시점에는 콘텐츠가 모두 준비되므로 **구현하지 않습니다.**

## 3. 이번 MVP에서 제외하는 항목

| 항목 | 비고 |
|---|---|
| `샘플 수업 시작하기` 버튼 | 제외 |
| 강의 만족도 / 누적 수강생 / 평균 점수 상승 수치 | 제외 |
| "이런 분께 추천해요" 영역 | 제외 |

| 강좌 요약의 `강의 구분(종합반/LC/RC)` | 제외. 배치표가 이미 LC·RC를 모두 담고 있어 중복 |

## 4. YBM이 전달하는 데이터

### 4-1. 고정 콘텐츠 (강사당 1벌)

| 항목 | 형태 |
|---|---|
| 해시태그 | 5개 내외 |
| 강사 한마디 | 1문장 |
| 강의 소개 글 | 소제목 + 본문 블록 2~3개 |
| 매칭 사유 문장 | 성향 조합별 세트 |

### 4-2. 매칭 산식

온보딩 성향 응답 2개 축을 강사의 성향 코드와 비교합니다.

```
기본 점수                     50
난이도 성향 일치 시           +30   (C 도전형 / S 안정형)
동기 성향 일치 시             +20   (P 목표자극형 / R 성취보상형)
─────────────────────────────────
결과값                        50 / 70 / 80 / 100
```

- 최고점 강사에게 **"AI 추천"** 배지가 붙습니다.
- 강사별 성향 코드는 배치표와 함께 전달합니다.

> **참고:** 원 설계는 4축(학습 범위 W/N, 학습 리듬 D/M, 난이도 C/S, 동기 R/P)이나,
> 현재는 **난이도·동기 2축만 점수에 반영**됩니다. 나머지 2축은 모든 강사가 충족하는 것으로 처리해
> 기본 50점에 포함돼 있습니다. 결과값이 4가지뿐인 이유입니다.

### 4-3. 강사별 커리큘럼 배치표

**강사 4명 × 학습 범위 성향 2종(W형·N형) = 8벌**을 전달합니다.

- 형태: 주차 / Day / 강의 1·2·3 / 복습 강의 / 학습 자료 / 목표
- 범위: D1~D20 (4주)
- **W형과 N형은 별도 설계입니다.** 한쪽을 규칙으로 변환해 다른 쪽을 만들 수 없습니다.
  (예: N형은 "LC를 모두 끝낸 뒤 RC"가 아니라, 초반에 LC를 선점한 뒤 LC·RC를 병행합니다.)

## 5. 커리큘럼 성격에 대한 사전 공유

- 커리큘럼은 **학습 데이터에 따라 실시간으로 바뀌는 동적 커리큘럼이 아닙니다.**
  성향 응답에 따라 미리 설계된 배치 중 하나를 선택해 보여주는 방식입니다.
- 다만 배치표의 **4주차는 "1~3주차 오답 데이터 기반 시험 직전 특강"** 자리로 설계돼 있습니다.
  이번 MVP에서는 **자리만 노출**하고, 실제 데이터 기반 재배치는 **다음 단계 범위**입니다.

## 6. 배치표 정리 이력 (YBM 내부)

> 개발사 전달 문서에서는 제외 가능합니다. 시트 → 코드 반영 시 처리한 내용입니다.

**반영 완료 (2026-08-03)** — 4명 × W/N = 8벌 전부 `src/data/instructorCurriculum.ts` 에 반영.
각 41강(LC 1~16 + RC 2~26), 중복·누락 없음, D1~D20 연속 검증 완료.

### 처리한 불일치

- **강의 번호 체계 통일.**
  박혜원·이도윤 시트는 `LC 3강`/`RC 2강` 표기에 LC Part 1이 **2강**,
  윤다은·서지안 시트는 `L4`/`R2` 표기에 LC Part 1이 **3강**으로 되어 있었습니다.
  DB(`lectures.seq`, LC 1~16)를 기준으로 후자를 아래 규칙으로 변환했습니다.

  | 시트 | DB |
  |---|---|
  | `L1` | `LC1` |
  | `L2` (Part 1 위치·전치사) | **제외** — DB에 없는 강의 |
  | `L3` ~ `L17` | `LC2` ~ `LC16` |
  | `R2` ~ `R26` | `RC2` ~ `RC26` (변환 없음) |

- **4주차 특강 표기 통일.**
  윤다은·서지안 시트의 내부 코드(`SR2`, `SL4` 등)는 학습자가 알아볼 수 없어
  코드를 떼고 파트·유형만 남겼습니다. (예: `SR2 Part5 동사·준동사` → `Part 5 동사·준동사 특강`)

- **이도윤 W형 설계 기준 문구 정정.**
  시트 원문은 "LC **17강** + RC 26강"이나 실제 배치도 DB도 LC 16강입니다.
  17강 기준 목록의 잔재로 보여 16으로 정정했습니다.

### 콘텐츠팀 확인 필요

- **RC 1강이 어느 강사의 어느 배치에도 없습니다.** 8벌 전부 `R2`/`RC2`부터 시작합니다.
  누락인지 의도인지 확인이 필요합니다. (DB에는 42강이 있고 배치는 41강입니다)
- **`L2` Part 1 위치·전치사** 강의가 윤다은·서지안 시트에만 있고 DB에는 없습니다.
  신설 예정 강의인지, 시트 쪽 오류인지 확인이 필요합니다.

# 결정 대기 큐

**이 파일은 "물어봤는데 아직 답을 못 받은 것"만 모은다.** 대화 속에 흩어져 있으면 매번 다시
설명해야 하고, 실제로 08-25 에 같은 걸 네 번 묻고도 답을 못 받았다. 여기 한 곳에 쌓아두고
하루 한 번 몰아서 답하면 된다.

**쓰는 법**
- Claude: `/memo` 의 **C 갈래(결정이 필요하다)** 가 나오면 여기에 블록을 하나 붙인다. 고르지 않는다.
- 사용자: `**답:**` 줄에 한 줄로 적는다. 그게 곧 지시다.
- 답이 적힌 블록은 처리한 뒤 맨 아래 **닫힌 것**으로 옮긴다(한 줄로 줄여서).

**블록 모양**

```
## (짧은 제목)
- 물은 날 · 출처(메모 N행 / PR #번호)
- 무엇이 걸리나: 한 문장
- 선택지: ① … ② …  ← Claude 안이 있으면 ★ 표시
**답:**
```
